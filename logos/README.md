# Oye Chakhna! Logo Concepts

This folder contains four editable SVG logo ideas for your brand **Oye Chakhna!**.

## Concepts

1. **Masala Burst** (`logo-1-masala-burst.svg`)
   - Warm Indian spice palette, bowl/chakhna visual, energetic rays.

2. **Cheers Glass** (`logo-2-cheers-glass.svg`)
   - Two clinking glasses + snack dots, a premium bar-snack vibe.

3. **Street Stamp** (`logo-3-street-stamp.svg`)
   - Badge-style street-food identity; works well for packaging stamps.

4. **Modern Monogram** (`logo-4-modern-monogram.svg`)
   - Stylized OC monogram for a more modern/lounge extension.

## Quick usage notes

- These are vector files (infinite scalability, easy to recolor).
- You can open/edit in Figma, Adobe Illustrator, Inkscape, or most browsers.
- If you want, I can next create matched variants:
  - monochrome print version,
  - dark-mode/light-mode lockups,
  - icon-only social profile versions.
